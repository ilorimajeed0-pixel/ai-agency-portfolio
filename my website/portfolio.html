Automation Logic

  • 01. Webhook receives form payload from patient inquiry page
  • 02. Validates required fields and normalises email format
  • 03. Routes based on inquiry type: dental, medical, or general
  • 04. Creates or updates matching CRM contact record via REST API
  • 05. Dispatches Slack message to relevant channel + sends email alert
  • 06. Marks inquiry as queued; triggers follow-up reminder workflow

Error Handling

  • ✓ Failed webhooks retry automatically 3×
  • ✓ Invalid email flagged for manual review
  • ✓ CRM sync errors logged to Slack alert channel
  • ✓ Full audit trail maintained per execution
  • ✓ Routing fallback for unrecognised inquiry types
